# 每周深读推荐记录

## 2026-07-05

- **书：**《噪声》· 丹尼尔·卡尼曼 / 奥利维耶·西博尼 / 卡斯·桑斯坦
- **章节：**第9章「判断与模型，简单的模型普遍优于人类判断」（7,552字）
- **方向：**挑战「AI 做流程、人做决策」的核心假设——简单的统计模型在判断力上碾压专家
- **碰撞点：**人类在决策中的不可替代性到底是判断质量还是主体性（归责）？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=d33327e0726c18a9d335459

## 2026-07-12

- **书：**《深度工作：如何有效使用每一点脑力》· 卡尔·纽波特
- **章节：**「忙碌代表生产能力」（2,480字）
- **方向：**挑战「优化流程 = 降低返工率」的假设——在知识工作中，忙碌本身可能是最深层的返工根因
- **碰撞点：**你的注意力预算被谁借走了？返工不是因为流程差，而是因为深层思考的时间被浮浅工作挤占
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=0e5327005de2450e58c115d

## 2026-07-19

- **书：**《升维：不确定时代的决策博弈》· 王珞
- **章节：**第3章「真正的决策都是不确定性决策」（11,936字）
- **方向：**挑战「把决策流程工程化 = 更好」的假设——真正的决策本质上是不确定性决策，确定性让人作恶，概率让人投机，不确定性引发敬畏之心
- **碰撞点：**在你越来越确定性的 Agent 系统中，还剩多少个「真正的决策」？还是在把决策能力一起工程化掉？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=ec532220728a99b3ec5d356

## 2026-07-26

- **书：**《还原与无限：技术时代的哲学问题》· 余明锋
- **章节：**第六章「绩效社会的暴力与自由——评韩炳哲的绩效社会论」（6,103字）
- **方向：**技术中介下的主体性——当AI代理替你在场，你自己的临在感和主体性还剩什么？
- **碰撞点：**余额胶囊每30秒刷新——它在提醒你「钱在烧」还是「你在烧」？绩效社会的终极形态是人不自知地把自己变成了需要不断优化KPI的机器
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=b3d32500813ab7e96g018006
