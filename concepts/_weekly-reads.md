# 每周深读推荐记录

## 2026-07-05

- **书：**《噪声》· 丹尼尔·卡尼曼 / 奥利维耶·西博尼 / 卡斯·桑斯坦
- **章节：**第9章「判断与模型，简单的模型普遍优于人类判断」（7,552字）
- **方向：**挑战「AI 做流程、人做决策」的核心假设——简单的统计模型在判断力上碾压专家
- **碰撞点：**人类在决策中的不可替代性到底是判断质量还是主体性（归责）？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=d33327e0726c18a9d335459

## 2026-07-12

- **书：**《深度工作：如何有效使用每一点脑力》· 卡尔·纽波特
- **章节：**「忙碌代表生产能力」（2,480字）
- **方向：**挑战「优化流程 = 降低返工率」的假设——在知识工作中，忙碌本身可能是最深层的返工根因
- **碰撞点：**你的注意力预算被谁借走了？返工不是因为流程差，而是因为深层思考的时间被浮浅工作挤占
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=0e5327005de2450e58c115d

## 2026-07-19

- **书：**《升维：不确定时代的决策博弈》· 王珞
- **章节：**第3章「真正的决策都是不确定性决策」（11,936字）
- **方向：**挑战「把决策流程工程化 = 更好」的假设——真正的决策本质上是不确定性决策，确定性让人作恶，概率让人投机，不确定性引发敬畏之心
- **碰撞点：**在你越来越确定性的 Agent 系统中，还剩多少个「真正的决策」？还是在把决策能力一起工程化掉？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=ec532220728a99b3ec5d356

## 2026-07-26

- **书：**《还原与无限：技术时代的哲学问题》· 余明锋
- **章节：**第六章「绩效社会的暴力与自由——评韩炳哲的绩效社会论」（6,103字）
- **方向：**技术中介下的主体性——当AI代理替你在场，你自己的临在感和主体性还剩什么？
- **碰撞点：**余额胶囊每30秒刷新——它在提醒你「钱在烧」还是「你在烧」？绩效社会的终极形态是人不自知地把自己变成了需要不断优化KPI的机器
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=b3d32500813ab7e96g018006

## 2026-08-09

- **书：**《值得信赖的顾问：成为客户心中无可替代的人》· 大卫·梅斯特 / 查理·格林 / 罗伯特·加弗德
- **章节：**第4章「如何提出建议」（6,788字，17分钟）
- **方向：**盲区（信任/人际关系 0/32）——用「提出建议的权利」框架挑战「功能对比」式销售
- **碰撞点：**Clement 问的是功能，但真正需要的是帮他管理老板预期——在赢得建议的权利之前，所有功能对比都是噪音
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=285329d05e3d0d285f91787

## 2026-08-16

- **书：**《精力管理》· 吉姆·洛尔 / 托尼·施瓦茨
- **章节：**第一章「什么是精力及如何管理精力」（8,049字）
- **方向：**盲区（个人能量/恢复 0/32）——挑战「效率=时间管理」的假设，把镜头从「系统」拉回「自己」
- **碰撞点：**时间每天恒定，精力是可再生资源；巅峰表现靠「冲刺—恢复」节奏而非一直满负荷。你给客户搭提效系统，你自己有恢复系统吗？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=4263296071f8f0464264d41

## 2026-08-23

- **书：**《卡片笔记写作法：如何实现从阅读到写作》· 申克·阿伦斯
- **章节：**「写作是唯一重要的事情」（2,059字，5分钟）
- **方向：**盲区（知识生产/写作驱动 0/33）——用卢曼卡片盒的「写作驱动」冲撞「收集+复习」知识系统惯性，接住 8/21 阅读分析暴露的「读→用转化率」盲区
- **碰撞点：**写作不是思考的副产品而是思考本身；不产出文字的笔记只是收藏癖。如果知识库里只有「被写进文章/方案/话术的卡片」才算存在，33 个概念文件还剩几个？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=3d8326d072552e803d87c41

## 2026-08-31

- **书：**《销售巨人：大订单销售训练手册》· 尼尔·雷克汉姆
- **章节：**第17章「暗示问题」（5,695字，14分钟）
- **方向：**盲区（谈判/需求心理 0/34）——接住本周「雷达跟进动作太机械」+ 丽新案（客户被失败伤过）：「大订单的成交开关在客户没说出来、数据扫不到的地方」
- **碰撞点：**升级信号清单（主题34）告诉去哪家，SPIN 研究（3.5万次拜访）说成交预测因子是提问质量而非方案陈述——暗示问题让客户自己说出「问题不解决的代价」。如果 12 家商机的跟进动作都改成「一个问题」而不是「一条资料」，哪家先松动？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=fea329b0813ab9957g0166d2
