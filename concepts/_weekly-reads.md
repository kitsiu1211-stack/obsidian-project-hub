# 每周深读推荐记录

## 2026-07-05

- **书：**《噪声》· 丹尼尔·卡尼曼 / 奥利维耶·西博尼 / 卡斯·桑斯坦
- **章节：**第9章「判断与模型，简单的模型普遍优于人类判断」（7,552字）
- **方向：**挑战「AI 做流程、人做决策」的核心假设——简单的统计模型在判断力上碾压专家
- **碰撞点：**人类在决策中的不可替代性到底是判断质量还是主体性（归责）？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=d33327e0726c18a9d335459

## 2026-07-12

- **书：**《深度工作：如何有效使用每一点脑力》· 卡尔·纽波特
- **章节：**「忙碌代表生产能力」（2,480字）
- **方向：**挑战「优化流程 = 降低返工率」的假设——在知识工作中，忙碌本身可能是最深层的返工根因
- **碰撞点：**你的注意力预算被谁借走了？返工不是因为流程差，而是因为深层思考的时间被浮浅工作挤占
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=0e5327005de2450e58c115d

## 2026-07-19

- **书：**《升维：不确定时代的决策博弈》· 王珞
- **章节：**第3章「真正的决策都是不确定性决策」（11,936字）
- **方向：**挑战「把决策流程工程化 = 更好」的假设——真正的决策本质上是不确定性决策，确定性让人作恶，概率让人投机，不确定性引发敬畏之心
- **碰撞点：**在你越来越确定性的 Agent 系统中，还剩多少个「真正的决策」？还是在把决策能力一起工程化掉？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=ec532220728a99b3ec5d356

## 2026-07-26

- **书：**《还原与无限：技术时代的哲学问题》· 余明锋
- **章节：**第六章「绩效社会的暴力与自由——评韩炳哲的绩效社会论」（6,103字）
- **方向：**技术中介下的主体性——当AI代理替你在场，你自己的临在感和主体性还剩什么？
- **碰撞点：**余额胶囊每30秒刷新——它在提醒你「钱在烧」还是「你在烧」？绩效社会的终极形态是人不自知地把自己变成了需要不断优化KPI的机器
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=b3d32500813ab7e96g018006

## 2026-08-09

- **书：**《值得信赖的顾问：成为客户心中无可替代的人》· 大卫·梅斯特 / 查理·格林 / 罗伯特·加弗德
- **章节：**第4章「如何提出建议」（6,788字，17分钟）
- **方向：**盲区（信任/人际关系 0/32）——用「提出建议的权利」框架挑战「功能对比」式销售
- **碰撞点：**Clement 问的是功能，但真正需要的是帮他管理老板预期——在赢得建议的权利之前，所有功能对比都是噪音

## 2026-08-16

- **书：**《精力管理》· 吉姆·洛尔 / 托尼·施瓦茨
- **章节：**第一章「什么是精力及如何管理精力」（8,049字）
- **方向：**盲区（个人能量/恢复 0/32）——挑战「效率=时间管理」的假设，把镜头从「系统」拉回「自己」
- **碰撞点：**时间每天恒定，精力是可再生资源；巅峰表现靠「冲刺—恢复」节奏而非一直满负荷。你给客户搭提效系统，你自己有恢复系统吗？
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=4263296071f8f0464264d41

## 2026-08-23

- **书：**《卡片笔记写作法：如何实现从阅读到写作》· 申克·阿伦斯
- **章节：**「写作是唯一重要的事情」（2,059字，5分钟）
- **方向：**盲区（知识生产/写作驱动 0/33）——用卢曼卡片盒的「写作驱动」冲撞「收集+复习」知识系统惯性，接住 8/21 阅读分析暴露的「读→用转化率」盲区

- **微信读书：** https://weread.qq.com/book-detail?type=1&v=3d8326d072552e803d87c41

## 2026-08-31

- **书：**《销售巨人：大订单销售训练手册》· 尼尔·雷克汉姆

## 2026-09-16

- **书：**《影响力（全新升级版）》· 罗伯特·西奥迪尼
- **章节：**第7章 承诺与一致 · 「承诺是关键」（6,765字，约17分钟）
- **方向：**盲区（说服 / 行为心理机制 0/35）——34 个主题都在讲「系统怎么搭、数据怎么说话」，没有一条讲「人对什么信号会自动反应」。接住 09-10 周周碰的「案例吃透 / 客户用不用得起来」痛点
- **碰撞点：**顺序是反的——人不是先被说服再行动，而是先做出一个自愿、公开、要付出努力的小动作，再自己把信念改写成配得上这个动作的样子。所以「买了 9900 用不起来」可能不是价值没讲清，而是缺一个客户自己的公开小承诺（自己演示一次、自己发一次用量截图）。顺带说破：大赛造势 = 公开承诺 + 社会认同，额度焦虑 = 稀缺，CEO 站台 = 权威——一直被归档在「组织推动力」四个字下，缺一层机制命名
- **自评（cron 模式，无独立 Evaluator）：**认知匹配度 8 / 推荐理由质量 8 / 多样性 8（首次引入社会心理学实验范式，与近 8 周噪声、深度工作、升维、绩效社会、值得信赖的顾问、精力管理、卡片笔记、SPIN、工匠精神均不重叠）
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=9ad32d40727950039add092 （本章 deeplink: weread://reading?bId=41504771&chapterUid=104）

## 2026-09-20

- **书：**《福格行为模型：你会越来越有能量》· B.J.福格
- **章节：**「明明拥有动机却还是无法改变的5个原因」（4,550字，约11分钟）
- **方向：**盲区（行为改变机制 / 采纳科学 0/35）——接住本周两条线：9/20 卡内基捐两千座图书馆「楼和书都到位、读者没长出来」（供给≠使用）、9/18 徐鸿浩国企全员发 WorkBuddy 基本没人用（发多了=没人觉得是自己的）。挑战主题34「组织推动力=一把手站台+大赛造势」——本质是拉动机，而福格模型（行为=动机×能力×提示）说动机最不可靠、最先被拉满，行为不发生的开关在能力与提示
- **碰撞点：**如果客户意愿没问题（都想要），卡住他们的是能力还是提示？下一场大赛/培训，是把动机再拉满一次，还是把某个动作拆到「不费劲、有锚点、做完立刻有感觉」
- **自评（cron 模式，无独立 Evaluator）：**认知匹配度 8（本周摩擦主线是采纳/供给≠使用，35 概念中无一条讲行为发生机制；区别于 09-16《影响力》的承诺-一致——那条是说服/合规，这条是能力门槛+提示+情绪固化）/ 推荐理由质量 8（具体指向主题34 组织推动力、9/18 WorkBuddy、9/20 卡内基图书馆三处，非泛泛「好书」）/ 多样性 8（近 10 周：噪声→深度工作→升维→绩效社会→值得信赖的顾问→精力管理→卡片笔记→SPIN→工匠精神→影响力；首次引入行为设计/习惯科学，与影响力同属心理学但有邻接，故不给 9）
- **微信读书：** https://weread.qq.com/book-detail?type=1&v=614325a07273de5c614b852 （本章 deeplink: weread://reading?bId=41147996&chapterUid=106）
