# 主题20：可复制性与涌现概率框架

## Compiled Truth

**涌现概率公式**：涌现概率 = 环境触发 × 内在可燃性 × 首次成功体验

四层运营框架（提高涌现概率）：
1. **识别**：发现"already have苗头"的人 → 提高转化率
2. **赋能**：效率先锋、开课分享 → 给舞台、给资源
3. **激励**：升职加薪、公开认可 → 让"主动者"被看见
4. **扩散**：大赛、创新土壤运营 → 把个体行为变成群体文化

关键洞察：你不能批量生产创新者，但可以提高创新的土壤肥沃度。

## 关键要点

- **涌现概率公式**：环境触发 × 内在可燃性 × 首次成功体验
- **可复制部分**：环境因素（信息透明、工具赋能、容错文化）可以设计和复制
- **难复制部分**：个体因素（内在动机、认知框架、试错勇气）依赖个人历史
- **四层运营**：识别火种 → 赋能舞台 → 激励认可 → 扩散文化
- **目标转换**：从"复制人"转向"提高涌现概率"

## 与训模型式管理的底层同构

*2026.6.18 补充——与主题4的跨主题串联*

涌现概率框架和训模型式管理共享一个**完整的逻辑链路**：

```
识别可燃的人 → 给环境触发 → 首次成功体验 → 自燃 → 扩散
    ↑                  ↑              ↑
 训模型·初始化      训模型·体验    涌现公式·首次成功
 涌现公式·可燃性    涌现公式·触发
```

**三步合一**：

1. **先筛选，不改造**：罗福莉说「不看经验看初始化」，涌现公式说「识别 already have 苗头的人」——本质上都是在找那些本身就容易被 AI 点燃的人。对石头浇水没用。

2. **给体验，不给教程**：不用全员培训，让那 2-3 个对 AI 天然好奇的人先用起来。他们的首次成功体验就是最好的「教程」——其他人看到效果后自然想学。

3. **让火自己烧开**：训模型管理的终点（Context not Control）和涌现框架的终点（扩散）是同一件事——当火种自己燃起来后，管理者不需要再「推」，只需要「不挡路」。
