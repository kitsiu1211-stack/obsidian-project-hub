# 主题34-AI赢单策略

> 来源：2026-08-26 五人 AI 赢单蒸馏沉淀（少特 7 单 / 珊珊 5 单 / 鑫杰 5 单 / 月楠 3 案例 / 梦迪 7 案例，合计近千万 ARR）。企业名已脱敏（某+行业+企业）。

## Compiled Truth

AI 赢单的核心只有三件事：**找到 AI 第一负责人、用场景用量说话、靠组织推动力放大消耗**。

**洞察 1：AI 第一负责人是关键人。**
CAIO / CIO / HR 负责人 / 技术负责人——他们是 29.7 万及以下金额的关键决策人，少数 99 万也是由他们发起。**CEO 一定是 99 万的关键决策点**：C-level 推 99 万时胆怵（不知道怎么向老板解释花公司的钱），需要老板站台 + 人效数据支撑。推 99 前先确认一把手态度。

**洞察 2：场景用量是货币。**
升级靠消耗数据说话，不靠关系靠数据。用量测算表（真实租户数据）是「一步到位」打法的核心武器——某大制造企业 754 万用量 → 600 万包 → 9900 直拉 29.7 万。

**洞察 3：组织推动力是放大器。**
一把手站台 + 大赛/培训造势，把自然消耗变成可控增长（某服装企业智能伙伴 100-200 人 → 1000 人）。高消耗必须一把手牵头宣贯。

**单类型边界（V3.1 修正）：**
- 新签 = 9900 → 99000：客户第一次真正买 AI（从只买 9900 智能纪要，到第一张 99000 正式包）
- 增购 = 99000 → 297000 / 990000：已有正式包后往上走

**升级信号清单（量化触发器）：**
- 9900 → 99000：消耗率 ≥ 2 倍；只用智能纪要单模块；激活人数上涨/办过大赛
- 99000 → 29.7 万：用量测算超档（真实数据 700 万+ → 600 万包）；半年内烧完 9.9 万；额度快用完 + 场景在长（豆包工作伙伴跑起来）
- 29.7 → 99 万：消耗曲线测算 8-10 个月用完；激活人数到千级（1000/4000/白领 6000）；一把手已公开表态拥抱 AI
- 反直觉：99 万不一定靠人数，1000 多人企业也到 99——关键是使用场景（某企业靠妙搭场景消耗起来）

**AI 第一负责人地图：**
- 29.7 及以下：CAIO / CIO / 技术负责人 / HR 负责人，找到他就成功一半；HR 拍板时拿外部工具开销背书
- 99 万：CEO 是唯一关键决策点
- 预算卡壳三招：版本切换腾挪（企业版→一线版）/ 安全权益下放先小步用 / 邀约老板降决策难度

**新签 4 条破冰线：** 需求驱动（研发要建 agent，抢在外部平台前让内部 IT 搬飞书统一管理）/ 决策人直连 / 活动转化（邀约标杆大会+案例抄作业）/ 焦虑营销（办大赛+制造同行配置焦虑）。

**增购 3 种打法：** 用量测算一步到位（话术：用量必超+立项复杂+不浪费）/ 大赛造势→消耗→升级 / 决策人管理痛点（功能为管理服务，找到管理诉求如高管看纪要无权限、想管控用量，功能只是抓手）。

**增购节奏：** 快用完时去聊，被拒续低档等下次，保持接触频率。

## 关键要点

- **AI 第一负责人**是 29.7 万及以下的关键人；**CEO 是 99 万的唯一关键决策点**
- **场景用量是货币**——升级靠消耗数据说话，用量测算表是一步到位核心武器
- **组织推动力是放大器**——一把手站台 + 大赛造势，把自然消耗变成可控增长
- **新签 = 9900→99000**（第一次真正买 AI）；**增购 = 99000→29.7/99**
- **升级三档触发器**：消耗率 ≥2 倍 / 用量测算超档 / 消耗曲线 8-10 个月用完 + 千级人数 + 一把手表态
- **99 万不一定靠人数**，关键是使用场景（妙搭场景也能打）
- **决策人管理痛点**：功能为管理服务，找到管理诉求，功能只是抓手
- **5 个反例**：高档被拒（尊重节奏先养量）/ 零消耗买家（识别管理型 vs 消耗型）/ 预算卡壳半年（拆开谈安全权益下放）/ 工具栈不匹配（先探清真实工具栈）/ 硬推无场景（饮鸩止渴，没场景宁可不签）
- **冷静期应对**：主动给场景人效数据 / 帮客户做场景规划 / 传递长期价值 / 管控诉求先试用半年（待与 CSM 协同展开）
