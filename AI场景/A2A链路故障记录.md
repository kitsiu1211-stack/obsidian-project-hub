# A2A 链路故障记录 — Agent 协作群

## Compiled Truth

A2A（Agent-to-Agent）链路指「Agent 协作群」内的任务分发与结果回收流程：

```
用户(鑫杰) → 浪子(Hermes) → [路由判断] → @目标Bot → 等回复 → [筛选+合成] → 返还用户
```

链路由两个关键环节构成：
1. **出站**：Hermes 理解任务 → 路由到最合适的 Bot → 发送 @ 消息 → 等待回复
2. **入站**：接收 Bot 回复 → 判断哪个结果最合适 → 筛选材料或总结方案 → 返还给用户

### 已确认故障（7/21 Kimi Code 案例）

#### 故障 1：@ 错目标 Bot
- **预期**：@ Kimi Code（`ou_75e812630b3c51fc879295c78424898c`）
- **实际**：@ 了不存在的 "Kimi Agent"（群内无此 Bot）
- **根因**：路由使用了错误的 Bot ID，未基于群成员列表做精确匹配
- **影响**：消息发给了不存在的 Bot，正确的 Bot 根本没收到任务

#### 故障 2：信息传递不完整
- **预期**：将用户的完整调查问题全部传给目标 Bot
- **实际**：只传了一半的问题，后续信息缺失
- **根因**：出站消息构建时截断了任务上下文，多段信息没有完整拼接
- **影响**：目标 Bot 收到的只是残缺任务，无法正确执行

### 环境

Agent 协作群 `oc_219a613c13292855c2dc4b80e59dfd6e`，11 个 Bot
- 互 @ 铁律：必须使用 `<at user_id="ou_xxx">` 格式，否则目标 Bot 收不到
- **修复**：已建立 Bot 路由映射表 → [[Agent协作群-Bot路由表]]
- 出站消息需保证上下文完整性（不截断多段信息）

## 关键要点

- **故障 1 — 路由错误**：未使用群成员列表做精确匹配，使用了错误的 Bot ID
- **故障 2 — 信息截断**：出站消息构建时多段任务上下文未完整拼接
- **严重程度**：两个故障叠加 = 消息发错人 + 内容残缺 = A2A 链路完全失效
- **修复方案**：已建立 Bot ID 路由映射表（[[Agent协作群-Bot路由表]]），路由前强制查表
