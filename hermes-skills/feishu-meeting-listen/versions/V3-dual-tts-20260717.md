# feishu-meeting-listen V3 双 TTS 版

## 架构

```
会议字幕(lark-cli +meeting-events)
  → DeepSeek LLM (思考生成回复)
  → 豆包 TTS (WebSocket 流式 / 主)
  → Fish Audio TTS (HTTP / 备用)
  → afplay 播放 → BlackHole → 会议麦克风
```

## 排坑记录

| 问题 | 原因 | 解决 |
|------|------|------|
| 豆包 TTS 返回 `data:null` | 用了旧版控制台 AppId+AccessKey，不是新版 API Key | 用 `X-Api-Key` header |
| 音色不匹配 | 用了 `zh_female_vv_uranus_bigtts` (Vivi) 而非 小何 | 改 `zh_female_xiaohe_uranus_bigtts` |
| 信息错乱 (前面说通后面说不通) | 凭据散落、没有持久化、复测时没用原凭据 | 统一到 `config/.env` + Obsidian 归档 |
